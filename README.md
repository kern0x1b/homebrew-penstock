# Penstock Homebrew tap

Installs the `penstock` command line, which checks, lints, lays out, draws and deploys BPMN diagrams.

```bash
brew tap kern0x1b/penstock
brew install penstock
```

The formula is written by the Penstock release and points at the package on the npm registry. See https://kern0x1b.github.io/penstock-release/ for the documentation.
